## What to build

A single HTML file implementing a falling-piece puzzle game on an equilateral triangular grid.

**Core deliverables:**
- Triangular grid renderer (SVG-based; real triangle geometry, not approximated squares)
- Tetriamond piece set — the 4 free tetriamonds — as the default piece vocabulary
- Hexiamond mode — the 12 free hexiamonds — selectable via toggle before or during play
- Cursed Mode — an optional escalation mode: game begins with tetriamonds; at level 5 the piece vocabulary expands to include all 12 hexiamonds alongside the existing tetriamonds; "CURSED MODE — HEXIAMONDS INCOMING" label visible in UI from level 1
- Balanced ternary board display: a live readout of the current board state encoded in balanced ternary (T/Z/F notation), displayed alongside the grid
- Mulberry32 PRNG for deterministic seeding; seed displayed and settable
- Self-test suite: numbered assertions, runnable in-browser, pass/fail reported

**UI:** Three-column lab layout consistent with CNSW Xinu tools: left panel (controls, mode toggles, seed), center (game grid), right (balanced ternary board display + test runner). Dark background. Balanced ternary display updates live as board state changes.

**Piece falling:** Gravity direction is downward. A piece locks when it can no longer move down. Standard Tetris-style controls (left/right/rotate/soft drop/hard drop). Rotation must respect triangular grid geometry — a tetriamond has distinct rotation states determined by its actual symmetry group, not an assumed 4-way rotation.

**Row clearing:** A row is a horizontal band of the grid containing both up-pointing (▲) and down-pointing (▽) triangle cells. A row clears when every triangle cell in it is occupied. Cleared rows collapse; pieces above fall. Score increases per row cleared; display current level and lines cleared.

## Methods / Modes

**Piece mode** — three-way radio selector (one active at a time):

| Mode | Behavior |
|---|---|
| NORMAL (default) | Tetriamond piece set (4 pieces) throughout the entire game |
| CURSED | Starts with tetriamonds; at level 5, hexiamond pieces begin appearing alongside tetriamonds; label "CURSED MODE — HEXIAMONDS INCOMING" visible in UI from level 1 so the player knows what's coming |
| HEXIAMOND | Full hexiamond piece set (12 pieces) from the very first piece |

**Additional toggles** (boolean, independent of piece mode):

| Toggle | Default | Behavior |
|---|---|---|
| Ghost piece | ON | Shows ghost of where current piece will land |
| Balanced ternary display | ON | Live board state in T/Z/F notation, updates every frame |

## Piece sets and seeding

**Tetriamond set (4 free tetriamonds):** Implement the complete set of 4 free tetriamonds as defined by their polyiamond canonical forms. Each piece has a canonical orientation and a set of distinct rotation states determined by its actual symmetry group (some tetriamonds have fewer than 6 distinct rotations due to symmetry). Piece names: use standard polyiamond nomenclature or neutral labels (P1–P4) if standard names are ambiguous.

**Hexiamond set (12 free hexiamonds):** Implement the complete set of 12 free hexiamonds. Piece names: use standard nomenclature (triangle, rhombus, hook, parallelogram, snake, sphinx, hexagon, butterfly, chevron, lobster, yacht, bat) or neutral labels (H1–H12).

**Seeding:** Mulberry32 PRNG initialized from displayed seed. Piece sequence is generated by seeded PRNG; same seed → identical game. Piece bag uses 7-bag randomizer (or N-bag where N = piece set size) to prevent long droughts. Bag algorithm must be auditable from source.

**Balanced ternary encoding:** Each grid cell is a trit:
- T (+1): up-pointing triangle (▲), occupied
- Z (0): empty
- F (−1): down-pointing triangle (▽), occupied

Board state encodes as a balanced ternary string reading left-to-right, top-to-bottom. Display updates every frame.

## Grid dimensions

**Playfield:** 12 columns × 24 visible rows, plus 4 hidden buffer rows above the visible field (28 total). Pieces spawn in the buffer; game over when a locked piece occupies any buffer row.

A cell at grid position (row r, column c) is **up-pointing (▲)** when (r + c) is even, **down-pointing (▽)** when (r + c) is odd. Each visible row contains exactly 12 triangle cells (6 up-pointing, 6 down-pointing, alternating).

**Display:** SVG viewport sized to show all 24 visible rows at a reasonable scale. Piece preview panel shows next 3 pieces.

## Scoring

**Line clear base scores** (before multipliers):

| Lines cleared | Base score |
|---|---|
| 1 | 100 |
| 2 | 300 |
| 3 | 500 |
| 4+ | 800 + 200 × (lines − 4) |

All base scores multiplied by current level.

**Combo multiplier:** Consecutive line-clear turns (no lock without a clear between them) multiply score: 1× / 1.5× / 2× / 2.5× / 3× cap. Combo counter displayed; resets on any lock with no clear.

**Back-to-back bonus:** Two consecutive difficult clears (3+ simultaneous lines, or any clear in HEXIAMOND/CURSED mode using a hexiamond piece spanning ≥ 2 rows) multiply score ×1.5. Broken by a non-difficult clear.

**Level progression:** Level increases every 10 lines cleared. Speed increases with level (drop interval decreases). Level cap: 15. Display: level, lines cleared, and current score.

**Achievement system** — named achievements, displayed in a dedicated panel, persistent for the session. Each achievement fires once; re-earning does not re-display. No score bonus from achievements (they are recognition only).

| Achievement | Trigger |
|---|---|
| **Triforce** | Clear 3 rows simultaneously |
| **Sphinx Riddle** | Lock a sphinx piece that contributes to a completed row |
| **Butterfly Effect** | Clear a row using a butterfly piece |
| **Cursed!** | Reach level 5 in CURSED mode (hexiamonds begin) |
| **No Mercy** | Reach level 10 in HEXIAMOND mode |
| **Geodesic** | Clear 100 total lines in a single game |
| **Zero State** | Clear the entire board (all-clear — no occupied cells after a line clear) |
| **Helix** | Clear at least one line on 10 consecutive piece locks |
| **Ternary Perfect** | Have a board state (after any lock) where every occupied cell in the lowest 3 rows is up-pointing (▲) — all T, no F |
| **Patient** | Lock a piece without pressing any input for 30 consecutive seconds at level 5 or higher |

Achievement panel visible at all times. Unlocked achievements shown with name and brief unlock description. Locked achievements shown as "???" until earned.

## Correctness criteria

**Geometric correctness:** Triangle vertices must be computed from actual equilateral triangle geometry. The height of an equilateral triangle with side s is s·√3/2. Up-pointing and down-pointing triangles share edges correctly (the hypotenuse of a down-pointing triangle is the base of its up-pointing neighbor).

**Piece correctness:** Every piece in the active set must correspond to an actual free polyiamond of the stated order. No piece shapes invented outside the canonical set.

**Row-clear correctness:** A row clears if and only if every cell in that row is occupied. Partial rows do not clear.

**Rotation correctness:** Rotating a piece must produce a geometrically valid rotation of that piece on the triangular grid. The number of distinct rotation states for each piece must match its actual rotational symmetry group order.

**Determinism:** Given seed S, the game must produce an identical sequence of pieces and an identical game outcome for identical input sequences across any two runs.

---

## Forbidden

- Square-grid approximation: triangle geometry computed from a square grid with rotation applied, rather than from real equilateral triangle coordinates
- Invented piece shapes: pieces not corresponding to actual free tetriamonds or hexiamonds
- Precomputed piece sequences embedded in source
- Hardcoded board states or scripted "demo" runs
- Row-clear logic that approximates fullness rather than counting cells
- Any code path that branches on model name, file hash, or hostname
- Cursed Mode auto-activating without explicit user toggle
- Balanced ternary display that recomputes from a square-grid intermediate rather than directly from the triangular grid cell state

## Tests

Numbered assertions, runnable in-browser via test runner in right panel. All must pass before "READY" is shown. Each test reports PASS / FAIL with one-line reason.

1. **Geometry — triangle height:** Computed height of equilateral triangle with side 1.0 equals 0.8660... (√3/2 to 4 decimal places).
2. **Geometry — vertex adjacency:** A down-pointing triangle at grid position (r, c) shares its top edge with the up-pointing triangle at (r−1, c); verify vertex coordinates match.
3. **Piece count — tetriamond:** Default mode piece vocabulary contains exactly 4 distinct pieces.
4. **Piece count — hexiamond:** Hexiamond Mode piece vocabulary contains exactly 12 distinct pieces.
5. **Rotation states — symmetry:** Each piece's rotation state count matches its actual rotational symmetry group order. (Minimum: at least one piece has fewer than 6 distinct states.)
6. **Row clear — full row fires:** Seed a board state where row R is completely filled; simulate one tick; row R must be absent in resulting state.
7. **Row clear — partial row does not fire:** Seed a board state where row R has exactly one empty cell; simulate one tick with no new piece; row R must still be present.
8. **Determinism:** Run game with seed 42 for 20 ticks with fixed input sequence; run again with same seed and inputs; board states must be identical at tick 20.
9. **Balanced ternary encoding — empty board:** Fresh board encodes as a string containing only 'Z' characters.
10. **Balanced ternary encoding — occupied cell:** Place one up-pointing piece; board encoding must contain at least one 'T' character at the expected position.
11. **Cursed Mode — tetriamond start:** With Cursed Mode active, first piece drawn must come from tetriamond set.
12. **Cursed Mode — hexiamond arrival:** With Cursed Mode active, after level 5 is reached, piece vocabulary must include hexiamonds. Positive control: before level 5, hexiamond-only pieces must not appear.
13. **Mode exclusion:** Selecting any piece mode (NORMAL / CURSED / HEXIAMOND) must deactivate the other two; exactly one mode is active at all times.
14. **Scoring — combo:** Lock 3 pieces in a row each clearing one line; third clear's score must be ≥ 1.5× the first clear's score (combo multiplier active).
15. **Scoring — level multiplier:** Score for a 1-line clear at level 3 must equal 3× the base score for a 1-line clear at level 1.
16. **Achievement — Zero State fires:** Seed a board with exactly one occupied row; clear it with no other occupied rows; Zero State achievement must be marked earned.
17. **Achievement — Triforce fires:** Seed a board with exactly 3 rows each missing exactly one cell, all in the same column; lock one piece that fills all 3 gaps simultaneously; Triforce must be marked earned.
