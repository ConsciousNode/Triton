Triton

A balanced-ternary computer: trits (−1, 0, +1), from the instruction set to a desktop.

TritOS Desktop 1.1.1 → A graphical OS written entirely in Triton guest assembly: windows, a file system, StudioNet networking, and 11 apps, including Trytris (the [T3] button on the taskbar). Runs on Triton 3.1.1, which fixes the 3.1 bug where the keyboard and mouse stopped responding after about 2,048 input events. Triton 3.1.1 machine → The bare machine with TritOS 3, the text-mode OS, plus a self-hosting assembler. JS and WASM cores run in lockstep. Triton 2.1 (reference) → The earlier reference machine.
